Hilfe
Minecraft Host-Port: Java-Port auf dem Host, intern 25565.
Extra Ports: mehrere Ports mit Komma, Leerzeichen oder Zeilenumbruch trennen, z. B. 19132:19132/udp, 24454:24454/udp.
RCON Host-Port: eindeutiger Host-Port je Server, z. B. 25575, 25576.
RCON Container-Port: kann meist 25575 bleiben.
Min/Max RAM: optional; leer lassen, wenn MEMORY reichen soll.
Backups: liegen zentral im Backup-Ordner und enthalten den Containernamen im Dateinamen.
Plugins.txt:
  # deaktiviert eine Zeile
  BlueMap modrinth:bluemap
  Geyser modrinth:geyser
  Floodgate https://github.com/GeyserMC/Floodgate
  CoreProtect https://github.com/PlayPro/CoreProtect
  CoreProtect https://github.com/PlayPro/CoreProtect:master

CoreProtect wird aus dem GitHub-Source-Zip gebaut. Dafuer braucht der Host kein git, aber curl/wget und entweder mvn oder Docker fuer den Maven-Container.
Manuelle Plugins werden in DATA_DIR/plugins/manuell gespeichert und beim Containerstart vom Minecraft-Server geladen.
