# Bundled Java item catalog

`items.json` is generated by `tools/update_item_catalog.py`, for Minecraft Java 26.1.
The catalog is a selection aid, not a claim that every item is available on every
server. Custom IDs and newer/modded items may still be entered manually.

- Item IDs and English names: [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data/tree/201ca802a1b2c968b02e7fa5b31dd74e8bff3d8b/data/pc/26.1), whose README declares MIT licensing.
- Texture data: [PrismarineJS/minecraft-assets](https://github.com/PrismarineJS/minecraft-assets/tree/6c571b0825ee27b81f01127c2bd0d4ba2c89abb9/data/26.1), extracted Minecraft textures. These textures are Mojang/Microsoft game assets, not original artwork covered by this project's MIT license.
- Rendered fallback icons for all 16 beds and 73 previously missing textures: [Webisso/minecraft-item-icons](https://github.com/Webisso/minecraft-item-icons/tree/36475eb8d6093597001c3c0549662b04786305ef/public), pinned thumbnails. Its MIT notice is included in [ITEM_ICONS_LICENSE.txt](ITEM_ICONS_LICENSE.txt); Minecraft artwork remains owned by Mojang/Microsoft. The generator downloads these at build time and embeds them in the local catalog. `iconLayout: "contain"` distinguishes complete renders from raw animated texture strips.
- Remaining 21 icons (12 shelves, pale oak fence, 8 copper bar variants): [Block Render](https://blockrender.dev/), 64px item renders from its Java 26.2 models, downloaded on 2026-10-18. Exact URLs, SHA-256 checksums and image bytes are vendored in `tools/item_icon_overrides.json` because this service has no versioned URLs. Regeneration uses these checked local copies. These images depict existing 26.1 items; they do not change the catalog version. [Provider usage notes](https://blockrender.dev/docs/caching-and-limits/#using-the-images); textures and artwork belong to Mojang/Microsoft.
- German display names: Mojang's Java asset `minecraft/lang/de_de.json`, hash `b29f0ba4b2ce28b1b91a540d50455ecc632bfb41`, obtained from the official 26.1 asset index.

Minecraft names, translations and textures belong to their respective owners.
This project is not an official Minecraft product and is not endorsed by Mojang or Microsoft.
Exact source URLs are also recorded in the JSON. All 1,505 catalog entries have PNG icons. Only manually entered IDs outside this catalog use a neutral symbol. The generator validates completeness before replacing the catalog.
The browser uses the bundled file; it does not contact these providers when opening the picker.
